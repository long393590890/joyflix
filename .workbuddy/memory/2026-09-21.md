- 已知机制（Vercel 社区+官方文档）：Vercel 按**项目创建日期**决定 pnpm 9/10，不必然用 packageManager 钉的版本；要精确使用需设环境变量 `ENABLE_EXPERIMENTAL_COREPACK=1`。

- 下一方案（已建议）：Vercel 项目 Settings → General → Install Command 覆盖为 `npm install -g pnpm@10.14.0 && pnpm install --frozen-lockfile`，绕开 corepack；备选 COREPACK_INTEGRITY_KEYS=0。
